# 사이클 래그 폐기 이후의 잔차 따라잡기

메모. 2026-09-10.  
짝 문서: [THESIS.md](THESIS.md). 계산 원본은 ls-crude 102·103.

## 질문

097이 “60일 사이클 래그 엔진이 표본 밖에서 단순보유를 이긴다”를 기각한 뒤에도 더 좁은 주장은 남는다.

\[
HIR_t = R^{HLX}_t - \mathbb{E}[R^{HLX}_t \mid \text{원유·석유서비스 요인}]
\]

\(Z(HIR_t)\)가 충분히 음수일 때, 헬릭스가 피어 바스켓 대비 따라잡는가.

“떨어졌으니 오른다”가 아니다. 대상은 피어 중립 따라잡기다.

## 설계 (홀드아웃을 열기 전에 고정)

| 항목 | 규칙 |
| --- | --- |
| 테이프 | HLX, 2026-09-01까지. HOS와 잇지 않음 |
| 일상 증명 창 | 2026-04-21로 종료 |
| 인수합병 격리 | 2026-04-22–2026-09-01. 증명에 쓰지 않음 |
| 기대수익 | 인과 롤링 Ridge, \(\lambda=1\), 252세션 |
| 표준화 | 과거 잔차만 |
| 기본 사건 | \(Z \le -1.50\) |
| 체결 | 다음 세션, 20세션, 비중첩 |
| 손익 | \(R^{HLX}-R^{OSB}-40bp\) |
| 개발 | 2012-01-03–2021-12-31, **청산일**로 퍼지 |
| 홀드아웃 | 2022-01-03–2026-04-21. 전진 전까지 봉인 |

Alpha-Lock은 인증된 홀드아웃에서 14문을 모두 통과해야 한다. 규칙을 새로 만든 그 자리에 홀드아웃을 열지 않는다.

## 읽는 법

같은 HLX 테이프에서 서로 다른 문장 셋이다.

1. 사이클 래그가 거래 가능한 선행이다. 표본 밖에서 거짓 (097).
2. \(Z\le-1.50\), 20세션에서 잔차가 OSB 대비 돌아온다. v19 홀드아웃에서 거짓 (102).
3. 투턴 확인이나 10세션 상한이 작성된 전진 규칙을 통과한다. 아직 거짓 (v22, v23). 평균이 플러스여도 사건 수·이웃 안정·부트스트랩 하한이 아니다.

OII는 상관 공간에서 가장 가까운 상장 쌍둥이다. 그 사실이 HLX–OII를 평균회귀 스프레드로 만들지는 않는다.

## 이 메모가 하지 않는 일

v22·v23 이후 홀드아웃을 다시 열지 않는다. \(n=40\)과 \(7/9\)를 낮추지 않는다. 합성 통과를 증명으로 쓰지 않는다. HOS를 잇지 않는다.

```
미입증
v19 실패 이후 홀드아웃 봉인
개발 줄은 사전 등록한 변경 하나일 때만 연다
```
